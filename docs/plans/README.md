# Historical Plans

Every document in this directory is a dated design or gate record. The
documents intentionally preserve the baseline, scope, decisions, and language
of the moment in which they were written. They are not live project-status
documents.

Read `../CURRENT_STATE.md` before using any plan. Later accepted amendments and
implemented code govern current behavior. Do not infer that work remains
unimplemented merely because an earlier section says "not begun", "nothing is
merged", or "awaiting review".
